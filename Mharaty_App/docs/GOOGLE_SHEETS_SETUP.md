# ربط تسجيل المتدربين بـ Google Sheet

## كيف يعمل
عند ضغط المتدرب "تأكيد التسجيل":
1. يُحفظ الطلب في Supabase (نسخة احتياطية).
2. يُرسل نفس الطلب إلى Google Sheet عبر Google Apps Script.

يُعتبر التسجيل ناجحاً إذا نجح أحد الاثنين، لذلك لا يضيع طلب إذا تعطل أحدهما.
الشيت يمنع التكرار تلقائياً (نفس الهاتف + نفس الكورس) ويحتوي عمود **الحالة** بقائمة منسدلة
(جديد / تم التواصل / مؤكد / تم الدفع / ملغي) لمتابعة المتدربين.

## الإعداد (5 دقائق)
1. أنشئ ملف Google Sheet جديداً باسم "تسجيلات مهاراتي".
2. من القائمة: **الإضافات ← Apps Script**، احذف الكود الموجود والصق محتوى `apps-script/Code.gs`.
3. غيّر `SECRET` إلى كلمة سرية من اختيارك، و`NOTIFY_EMAIL` إلى بريدك لتصلك رسالة عند كل تسجيل (اختياري).
4. اضغط **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   ثم وافق على الصلاحيات (تظهر رسالة تحذير لأن السكربت لم يُراجَع من جوجل؛ اختر Advanced ← Go to project).
5. انسخ رابط الـ Web app (ينتهي بـ `/exec`).
6. في ملف `.env` ضع:
   ```
   VITE_SHEETS_WEBHOOK_URL=الرابط-المنسوخ
   VITE_SHEETS_SECRET=نفس-الكلمة-السرية
   VITE_SHEETS_VIEW_URL=رابط-الشيت-نفسه-للعرض
   ```
7. أعد البناء: `npm run build`.

اختبار: افتح رابط الـ Web app في المتصفح؛ يجب أن يظهر `{"ok":true,...}`.

## ملاحظات
- أي تعديل لاحق على Code.gs يحتاج **Deploy ← Manage deployments ← Edit ← New version**.
- الكلمة السرية داخل التطبيق ليست سرية تماماً (تُستخرج من الـ APK)، وظيفتها فقط تقليل الطلبات العشوائية. المنع الفعلي للتكرار والتحقق يتم داخل السكربت.
- إن أردت **نموذج Google Forms** بدل Apps Script فهو ممكن، لكنه أقل استقراراً (يعتمد على أسماء حقول داخلية قد تتغير) ولا يمنع التكرار؛ لذلك اخترنا Apps Script.
